# Dados Públicos de São Paulo

Este projeto trata, documenta e abre em painéis dois conjuntos de dados abertos da Prefeitura de São Paulo sobre **solicitações de cidadãos** (SP156):

| | Conteúdo | Volume |
|---|---|---|
| **Base SP156 completa** | Portal de Dados Abertos (CKAN), 2015T1 a 2026T2 | 18.774.202 solicitações |
| **Camadas GeoSampa `sac_*`** | 94 camadas georreferenciadas (WFS) | 143.461 solicitações, abr–set/2020 |

O ponto de partida foi uma camada específica do GeoSampa, [Reativação de um abrigo ou ponto que foi extinto](./catalogo/reativacao-abrigos.md). Os dados desta camada eram poucos (45 registros); a análise de contexto levou à base completa.

## O que o site não faz
- **Não publica linhas individuais, endereços ou logradouros.** Só agregados. Células de mapa com menos de 5 solicitações são ocultadas.
- **Não normaliza por população.** Os mapas mostram contagens, não taxas.
- **Não compara prazos antes de 2020**, porque o campo da fonte não representa a finalização nesse período.
- **Não tem vínculo oficial** com a Prefeitura de São Paulo.
